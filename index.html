✈️ Air-Gapped Code Wallet Transaction Flow

This guide outlines the highly secure, offline process of initiating a crypto transaction using a specialized Hardware Security Module (HSM) in an air-gapped environment, minimizing external exposure and maximizing security.

1

1. Transaction Initiation (Workstation)

The user starts the transaction on a machine that may be connected to the internet (Workstation).

Action: The user generates the transaction payload (recipient address, amount, fee).
Output: A simple, non-sensitive text file containing the raw transaction data (e.g., JSON or simple hex format).
Security Point: The private key *never* leaves this device.
2

2. Physical Transfer (Air Gap)

The critical step of transferring data across the air gap. No network connection is used.

🛑 AIR GAP BREACH POINT 🛑

The user copies the raw transaction file from the Workstation onto a dedicated, sanitized physical medium (e.g., a USB drive).

Protocol: The medium is physically carried to the isolated network segment. The medium must be verified for malware before use.
3

3. HSM Processing (Isolated Network)

The dedicated machine connected to the HSM processes the transaction in complete isolation.

Action:
  1. The operator loads the transaction payload from the USB drive into the isolated device.
  2. The HSM is prompted to sign the raw transaction data.
  3. M-of-N Security: Multi-party control (M-of-N) is required. Multiple trusted individuals (M) must physically verify and approve the transaction details/signing process before the HSM will release the signature.
Output: The HSM produces the cryptographically signed transaction package (the final, immutable proof).
4

4. Verification and Completion

The final, signed transaction is viewed and confirmed by all parties involved before being broadcast.

Verification: All parties must physically verify the signature details, recipient address, and amount displayed on the isolated machine.
Broadcast: Only once all physical checks pass, the signed transaction is copied onto a new, clean medium and transferred to the final network for broadcast.

🔒 **Security Summary:** By enforcing physical separation and multi-person control, the attack surface is drastically reduced, ensuring that the private signing key never touches an untrusted network.
